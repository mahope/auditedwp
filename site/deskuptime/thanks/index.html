Thank you — DeskUptime Pro is yours.

Your license key is on its way to your inbox (check spam if you don't see it within a few minutes). Follow the steps below to activate.

1 · Activate in the CLI

Run this once — it get unlimited URLs, faster intervals and desktop notifications:

curl -fsSL https://raw.githubusercontent.com/mahope/deskuptime/main/tools/install.sh | bash
deskuptime activate YOUR-LICENSE-KEY
deskuptime status           # confirm "Pro license: active"

2 · Or activate in the desktop app

Open DeskUptime → Settings → License → paste your key → Activate.

Downloads:

Download for macOS / Windows

3 · Start monitoring

deskuptime watch https://yoursite.com --interval 300

You'll get a notification the moment the site goes down, SSL is about to expire, or content changes.
