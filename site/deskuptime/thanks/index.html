1 · Activate in the CLI

Run this once — it get unlimited URLs, faster intervals and desktop notifications:

deskuptime status           # confirm "Pro license: active"

2 · Or activate in the desktop app

Open DeskUptime → Settings → License → paste your key → Activate.

3 · Start monitoring

deskuptime watch https://yoursite.com --interval 300
