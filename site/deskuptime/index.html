What you can monitor

Uptime & Response

HTTP status codes, redirect chains, and response time measurement. Know when your site is down — and how fast it loads.

SSL Certificate

Content Changes

SHA-256 content hash comparison between checks. Detect unauthorized changes, injected scripts, or broken layouts.

Frequently asked questions

Short answers to the questions people actually ask.

Does DeskUptime work with any website?

Yes. It takes any URL and checks it over plain HTTP — WordPress, Shopify, Wix, Squarespace, Webflow, static sites, hand-coded HTML. No plugin or integration is ever installed on the site you monitor.

Do I need my computer running all the time?

For continuous background monitoring in watch mode, yes — that's the trade-off for a $19 one-time price instead of a monthly SaaS bill. For quick "is it up right now?" checks, no: run a check from the CLI or this page any time.

What happens after I buy?

You receive a license key instantly by email from Lemon Squeezy (our payment provider). Enter it once in the desktop app and Pro features get. 3 activations per license, no DRM phone-home.

Is there a subscription?

No. $19 one-time covers all v1.x updates. If we ever ship a major new version, existing customers get a discount — never an automatic charge.
