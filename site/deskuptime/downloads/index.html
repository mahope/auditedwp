Download DeskUptime

Desktop app for macOS and Windows — or the zero-dependency CLI via curl. Both work with the same license key.

Desktop app (Pro)

System-tray monitoring with native notifications for all your monitored URLs.

macOS

Apple Silicon → Intel →

Windows

Installer (.exe) → MSI package →

Requires a Pro license ($19 one-time). The app prompts you to activate on first launch.

⌨ CLI (free)

Uptime, SSL-expiry and content-change checks from any terminal. Node 18+. Zero dependencies.

curl -fsSL https://raw.githubusercontent.com/mahope/deskuptime/main/tools/install.sh | bash
deskuptime check https://yoursite.com
deskuptime watch https://yoursite.com --interval 300
