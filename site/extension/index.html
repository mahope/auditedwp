Install now (unpacked)

  1. Download the extension (ZIP) and unzip it.

  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the unzipped folder.

How it works

The extension uses the same public API as the web scanner — your URL is checked against five compliance criteria:

🔒

HTTPS + HSTS

TLS encryption and Strict-Transport-Security header. Required by GDPR Art. 32.

🍪

Cookie consent

Detects 15+ consent platforms (Cookiebot, OneTrust, CookieYes…). ePrivacy Directive requires prior consent.

📋

Forms & privacy link

Forms without a visible privacy-policy link are a top GDPR enforcement target (Art. 13).

📄

Legal pages

Privacy policy, imprint, terms, and EAA statement linked from the homepage.

🛡️

Security headers

CSP, X-Content-Type-Options, Referrer-Policy — OWASP baseline, NIS2 Art. 21.

🔍

Platform detection

Identifies the CMS or stack (WordPress, Shopify, Next.js, etc.) — purely informational.
