EUComply WordPress Plugin

The universal EUComply scanner runs on any website from this site — no install needed. The WordPress plugin is an optional deep integration for WordPress owners who want the same checks plus WordPress-specific ones, right inside their dashboard.

↓ Download v1.2.0 (free)

What it adds beyond the web scanner

  • WordPress core update status and plugin health
  • Backup detection and user/role review hints
  • Scheduled re-scans with email-ready summaries
  • One-click Pro report generation (same $79/yr license)

Installation

  1. Download the ZIP above.
  2. In wp-admin go to Plugins → Add New → Upload Plugin.
  3. Choose the ZIP, click Install Now, then Activate.
  4. Open Tools → EUComply and run your first scan.

Requirements

WordPress 5.8+ · PHP 7.4+ · No external services required for core checks.

License & privacy

The plugin is open source under GPL v2. It runs entirely on your own server; scans never leave your installation unless you generate a Pro report. See our privacy policy.
