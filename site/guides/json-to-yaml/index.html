How to Convert JSON to YAML (3 Ways)

📅 August 24, 2026 · 5 min read · Try the free converter →

If you work with APIs and configuration files, you've been there: a Kubernetes manifest needs your API response in YAML, a Docker Compose file needs values from a JSON config, or a colleague sent you data in the wrong format.

Here are three ways to convert JSON to YAML — from quick one-liners to a daily-driver desktop app.

Method 1: CLI Tools (Fastest for Developers)

Using qf (QuickFormat CLI)

The qf CLI is a zero-dependency tool that detects format automatically and converts in one command:

$ echo '{"name":"test","version":2}' | qf --to yaml
name: test
version: 2

Install it with:

$ npm install -g quick-format

Or run without installing:

$ npx quick-format --help

The CLI also handles file input:

$ cat data.json | qf --to yaml > config.yml
$ qf --from json --to yaml < data.json > output.yml

Using yq (Alternative)

The popular yq tool also converts between formats:

$ yq -P '.' data.json > data.yml  # -P = pretty print

However, yq only handles JSON ↔ YAML. QuickFormat's qf handles all five formats (JSON, YAML, CSV, TOML, XML) — one tool for every conversion.
