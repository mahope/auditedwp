Sechs Prüfungen, eine Übersicht

EUComply prüft Ihre Seite auf die wichtigsten EU-Compliance-Anforderungen. Das Dashboard zeigt sofort, was bestanden wurde und was zu tun ist.

🔒 SSL & HTTPS

Gültiges Zertifikat? HSTS-Header gesetzt? Gemischte Inhalte? Prüfung auf Basis der tatsächlichen Seiten-URL und Server-Antwort.

🍪 Cookie-Consent

Cookie-Banner aktiv? WP Consent API registriert? Erkennt gängige Consent-Plugins (Complianz, Cookiebot, CookieYes u.a.).

📋 DSGVO-Formulare

Formular-Plugins erkannt? Datenschutz-Seite verlinkt? Einwilligung-Checkbox vorhanden? Grundlage für Art. 6 DSGVO.

💾 Backup-Status

Backup-Plugin aktiv? Letztes Backup-Alter? Off-Server-Speicher konfiguriert? Erkennt UpdraftPlus, BackWPup, Jetpack u.a.

⚠️ Plugin & Core-Health

Veraltete Plugins? WordPress-Version aktuell? Ungepflegte Erweiterungen mit Sicherheitsrisiken? Prüft Update-Status.

📄 Rechtstexte

Datenschutzerklärung zugewiesen? Impressum vorhanden (TMG §5)? Barrierefreiheitserklärung (BFSG) veröffentlicht? Alle Pflichtseiten auf einen Blick.

FAQ — Häufig gestellte Fragen

Sendet das Plugin Daten an externe Server?

Nein. Alle Prüfungen laufen lokal auf Ihrer WordPress-Installation. Keine Telemetrie, kein Analytics, keine Datenübertragung an Dritte. Die Pro-Lizenzprüfung sendet lediglich einen Lizenzschlüssel an die Gumroad-API — keine Seiten-Daten.

Wo ist der Unterschied zu Complianz, Cookiebot & Co.?

Diese Plugins lösen ein einzelnes Problem (Cookies). EUComply kombiniert sechs Compliance-Dimensionen plus Dokumentengenerierung — ein Plugin statt sechs. Besonders wertvoll für deutsche Agenturen, die gleichzeitig DSGVO, BFSG und NIS2 erfüllen müssen.

Ist der generierte AVV rechtsgültig?

Der AVV folgt der Standardstruktur von Art. 28 DSGVO, wie sie von Aufsichtsbehörden und Compliance-Beratern verwendet wird. Wir empfehlen, das ausgefüllte Dokument bei hochwertigen Verträgen von einem Rechtsanwalt prüfen zu lassen. Das Plugin liefert die korrekte Vorlage, keinen Ersatz für Rechtsberatung.

Hilft das Plugin bei der Barrierefreiheit (BFSG)?

Ja. EUComply prüft, ob eine Barrierefreiheitserklärung auf Ihrer Seite veröffentlicht ist. Die Pro-Version generiert eine vollständige BFSG-konforme Erklärung. Das BFSG (Barrierefreiheitsstärkungsgesetz, Umsetzung der EAA) gilt ab Juni 2025 für die meisten EU-Websites.

Kann ich die Reports für meine Kunden verwenden?

Ja. Pro-Nutzer stellen in den Einstellungen ihren Agentur-Namen ein — generierte Reports erscheinen mit diesem Namen. Ein reines White-Label-Upgrade (ohne „Generiert von EUComply"-Fußzeile) ist für Agenturen mit 10+ Websites verfügbar.

Kann ich das Plugin auf mehreren Websites nutzen?

Die Free-Version ist unbegrenzt. Jede Pro-Lizenz gilt für eine Website. Agenturen mit 10+ Websites erhalten Rabatt beim Kauf von Volumenlizenzen.

Brauche ich eine Rechtsschutzversicherung?

EUComply gibt Ihnen eine technische Baseline und generiert korrekte Dokumentvorlagen. Für formelle Compliance-Zertifizierungen und hochwertige Verträge empfehlen wir einen qualifizierten Compliance-Berater oder Rechtsanwalt — das Plugin ist das Werkzeug, nicht der Berater.
