EUComply Pro

Die aktuelle Pro-Lizenz gilt für das WordPress-Plugin. Sie schaltet bearbeitbare HTML-Startdokumente und einen HTML-Bericht aus dem letzten WordPress-Scan frei.

Pro kaufen — 79 USD pro Website pro Jahr

Was Pro heute umfasst

  • Pro-Lizenz für WordPress

    Die Pro-Lizenz wird im kostenlosen WordPress-Plugin validiert.

  • Bearbeitbare HTML-Startdokumente

    Die Lizenz schaltet Start-HTML für einen Auftragsverarbeitungsvertrag, NIS2-/DORA-Lieferantenklauseln und eine Barrierefreiheitserklärung frei.

  • HTML-Bericht aus dem letzten Scan

    Das Plugin kann einen HTML-Bericht aus dem letzten WordPress-Scan erstellen und herunterladen.

  • Tägliche Scans in Ihrer eigenen WordPress

    Eine Pro-Website wird in Ihrer eigenen WordPress-Installation einmal täglich statt einmal wöchentlich gescannt, sodass der Verlauf Tage sammelt. Der Bericht nennt das Intervall, das Ihr eigener Server tatsächlich ausführt.

  • Scan-Verlauf: ein Eintrag je Tag, pro Prüfung

    Jeder Pro-Scan schreibt einen Eintrag je Tag mit dem Zustand jeder der elf Prüfungen, die das Plugin ausführt. Der Bericht zeigt die neuesten 12 und nennt, wie viele gespeichert sind.

  • E-Mail-Alarm, wenn eine Prüfung ausfällt

    Wenn eine Prüfung besteht und später fehlschlägt, verschickt das Plugin eine E-Mail an den Website-Inhaber mit dem Namen der Prüfung und der konkreten Abhilfe. Ein wiederholter Fehler verschickt nichts Neues.

  • Ein schreibgeschützter Berichtslink für Ihren Kunden

    Eine Pro-Lizenz erstellt einen schreibgeschützten Link, den der Kunde ohne Anmeldung öffnet, und derselbe Bericht lässt sich aus wp-admin als Datei herunterladen.

Geplante Funktionen, die heute nicht enthalten sind: tägliche Scans im gehosteten Dienst, ein Scan-Verlauf im gehosteten Dienst, den Sie ohne WordPress einsehen können, zur Laufzeit erstellte PDF-Berichte, ein verifizierbares Live-Badge, ein Kundendashboard und die Verwaltung mehrerer Websites.

Eine Pro-Lizenz deckt eine Website ab. Bezahlt wird über Stripe. Vollständige Dokumentvorlagen werden separat verkauft.
