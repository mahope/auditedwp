Frequently Asked Questions

What formats does QuickFormat support?
JSON, YAML, CSV, TOML, and XML. Convert between any combination, or format/validate within a single format.
Does QuickFormat send my data anywhere?
No. All conversion happens on your Mac. The app makes zero network requests. Your JSON, API keys, and data never leave your computer.
Which macOS versions are supported?
macOS 14 (Sonoma) and later. Both Apple Silicon and Intel Macs are supported. The app is native and lightweight (~8MB).
Does the CLI version come with the desktop app?
Yes. When you buy QuickFormat, you also get the CLI tool (`qf`). Run it from your terminal for scripting and automation. The CLI is also available separately as an npm package.
