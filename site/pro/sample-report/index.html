Detailed Check Results

  • ✓ Google Consent Mode v2 Consent Mode v2 default state found (ad_storage and analytics_storage).
  • ! IAB TCF One TCF signal found: __tcfapi. No IAB consent string is stored, so ad-tech partners cannot read the visitor's consent. → Store an IAB consent string through your CMP and expose it on __tcfapi. See https://iabeurope.eu/tcf/.
  • ✕ Third-party trackers Trackers found in the served markup: Google Analytics, Meta Pixel. No consent platform is loaded before them, so they fire before consent. → Block non-essential tags until the visitor consents (GDPR Art. 6 and ePrivacy require consent BEFORE the tracker loads, not a banner afterwards).
  • ✓ HTTPS & HSTS TLS 1.3 active, valid certificate (Let's Encrypt), HSTS max-age=31536000.
  • ✓ Cookie consent Consent banner detected and cookie categories are declared (GDPR Art. 13).
  • ✓ Forms & privacy link 5 forms detected, privacy policy linked in the footer.
  • ✓ Legal pages Privacy policy and terms of service found on common paths.
  • ! Security headers No Content-Security-Policy and no X-Frame-Options. NIS2 Art. 21 expects basic technical measures, and CSP is the one auditors ask for first. → Add Content-Security-Policy: default-src 'self'. Start in report-only mode and tighten from the violations it reports.
  • ✓ DORA page-signal markers Page-text markers found: Incident response / SOC reporting, Status page / uptime monitoring, SPF (email sender auth). This is not a DORA assessment.

This is the same set of checks the free scanner runs on every site, so nothing here is held back for Pro.

Recommended Fixes (priority order)

  1. IAB TCF — Store an IAB consent string through your CMP and expose it on __tcfapi. See https://iabeurope.eu/tcf/.
  2. Third-party trackers — Block non-essential tags until the visitor consents (GDPR Art. 6 and ePrivacy require consent BEFORE the tracker loads, not a banner afterwards).
  3. Security headers — Add Content-Security-Policy: default-src 'self'. Start in report-only mode and tighten from the violations it reports.
