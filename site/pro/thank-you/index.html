Activate your Pro WordPress license.

If you have purchased EUComply Pro, use the license key delivered by Stripe. The current license is for the WordPress plugin.

  1. 1

    Find your license key

    If you purchased Pro, use the key from your Stripe receipt or the delivery email. If you cannot find it, contact support with your purchase receipt.

  2. 2

    Install the free plugin

    Download the EUComply WordPress plugin, install it on the website covered by your license, and enter the key in the plugin settings.

  3. 3

    Run a WordPress scan

    The free plugin can run its WordPress checks. Pro then provides the editable HTML starter documents and the report from the latest scan.

  4. 4

    Generate the HTML report

    After the scan, use the plugin to create and download an HTML report. Runtime PDF reports and hosted monitoring are not included in the current Pro license.

What is included today?

Pro provides editable HTML starter documents for a DPA, NIS2/DORA vendor clauses and an EAA statement, plus an HTML report from the latest WordPress scan. Full templates are sold separately.
