Scans your WordPress site for GDPR, NIS2, DORA, and EAA compliance gaps. Free checks: SSL, cookies, backups, forms, plugin health. Pro generates DPA, NIS2 clauses, EAA statements and quarterly reports.

== Description ==

= Know your EU compliance status in 30 seconds =

EUComply checks your WordPress site against six EU compliance criteria:

1. **🔒 SSL & HTTPS** — Valid certificate? HSTS header? Mixed content?
2. **🍪 Cookie Consent** — Cookie banner active? WP Consent API registered?
3. **📋 GDPR Forms** — Form plugins detected? Privacy Policy linked? Consent checkbox?
4. **💾 Backup Status** — Backup plugin active? Last backup age? Off-server storage?
5. **⚠️ Plugin & Core Health** — Outdated plugins? WordPress version current? Known CVEs?
6. **📄 Legal Pages** — Privacy Policy assigned? Imprint/Impressum? EAA Accessibility Statement?

= How it works =

1. Install and activate the plugin
2. Go to your WordPress admin → EUComply
3. Click "Run scan now"
4. Review the pass/fail dashboard with fix guidance

=== No data leaves your site =

All checks run server-side on your WordPress installation. No external API calls, no telemetry, no analytics. Pro license validation is the only external request (site-key check, no site data transmitted).

== Installation ==

1. Upload the `eucomply` folder to `/wp-content/plugins/`
2. Activate the plugin through the 'Plugins' screen in WordPress
3. Go to EUComply in your admin menu and click "Run scan now"

Or search "EUComply" on wp.org and install directly.

== Frequently Asked Questions ==

= Does the plugin send data to external servers? =

No. All checks run locally in your WordPress installation. No data is sent to EUComply or any third party.

= How is this different from Complianz, CookieYes or WP Activity Log? =

Those plugins solve one compliance problem (cookies or audit logging). EUComply combines six compliance checks with document generation — it's a compliance monitor + document generator in one plugin.

= Can I white-label reports for my clients? =

Yes, Pro users can set their agency name in Settings. Generated reports carry that name. A white-label upgrade (no "Generated by EUComply" footer) is available for agencies covering 10+ sites.

= Is the generated DPA legally valid? =

The DPA follows the standard GDPR Art. 28 structure used across the EU. We recommend having a lawyer review the filled-in result for high-value contracts.

= What happens when I cancel Pro? =

The plugin continues in Free mode — dashboard and weekly scans remain active. Document generation, reports, and email delivery stop. No data is deleted.
